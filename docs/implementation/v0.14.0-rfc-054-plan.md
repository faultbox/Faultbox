# v0.14.0 RFC-054 gVisor Adoption — Implementation Plan

> **Status:** Draft, 2026-07-28. Branch: `epic/v0.14.0-gvisor`
> (worktree at `.claude/worktrees/v0.14.0-gvisor`).
> RFC: [`docs/rfcs/0054-gvisor-packet-and-file-mediation.md`](../rfcs/0054-gvisor-packet-and-file-mediation.md).
> Companion roadmap: [RFC-046](../rfcs/0046-beyond-l1-roadmap.md) (#114).
>
> **Cadence:** six milestones, each independently mergeable to the epic branch behind a
> green regression gate. Milestone 0 is a decision gate — if its spikes fail, the plan
> below changes shape and this document is revised before Milestone 1 starts.

## Scope recap

RFC-054 commits v0.14.0 to two stock-gVisor adoptions:

- **Path B** — `gvisor.dev/gvisor/pkg/tcpip` as a library: packet-level network faults.
- **Path C-lite** — stock `runsc` + seccheck remote sink: file-level I/O observation.

Out of scope, stated so nobody re-litigates it mid-release: no Sentry fork, no clock
virtualization, no RNG funnel, no determinism level above L1, no byte-level filesystem
*injection*.

## The regression gate

The user requirement is *"after every milestone we have to be confident that nothing
broken."* That is only meaningful if it's a command, not a feeling. **Every milestone ends
with this exact sequence green before the next one starts:**

```bash
# 1. Host gate — mirrors CI exactly (.github/workflows/ci.yml)
go build ./...
go vet ./...
go test $(go list ./... | grep -v '/testops$') -race -count=1

# 2. Cross-compile gate — the Lima/CI target
GOOS=linux GOARCH=arm64 CGO_ENABLED=0 go build -o /dev/null ./cmd/faultbox/
GOOS=linux GOARCH=arm64 CGO_ENABLED=0 go build -o /dev/null ./cmd/faultbox-shim/

# 3. testops gate — this IS the spec-corpus gate; the golden suite loads and
#    runs the shipped .star corpus. (An earlier draft of this plan listed a
#    separate `faultbox check` step; no such subcommand exists.)
make testops-prep && go test ./testops/... -race -count=1

# 4. Milestone-specific acceptance (listed per milestone below)
```

Three rules attached to it:

1. **Baseline first.** Milestone 0 captures the output of steps 1–4 on `main` into
   `docs/implementation/v0.14.0-baseline.txt`. "Nothing broken" means *diff against that
   baseline*, not "tests passed" — a pre-existing failure must not be mistaken for a
   regression, and a newly-skipped test must not hide behind a green run.
2. **No milestone lands with a skipped test it introduced.** A `t.Skip` for
   `runtime.GOOS != "linux"` is acceptable and must be paired with a `link/channel` or
   fixture-based equivalent that *does* run on the host.
3. **Every milestone is revertable.** One squashed commit per milestone on the epic branch,
   so a bad milestone is `git revert`-able without unpicking later work.

## Milestone 0 — Spikes & decisions

**Goal:** eliminate every unknown that could invalidate the design, before writing
production code. Nothing in this milestone ships; everything produces a decision record.

### 0.1 Dependency viability — ✅ DONE (2026-07-28)

Full result in
[RFC-054 § Decision record M0.1](../rfcs/0054-gvisor-packet-and-file-mediation.md#decision-record-m01--dependency-viability).
Summary:

- **Pin `gvisor.dev/gvisor v0.0.0-20260224225140-573d5e7127a8`.** gVisor **head does not
  build as a module dependency** — `pkg/tcpip/stack` carries two different external test
  package names (`stack_test` *and* `bridge_test`) in one directory, which is invalid Go
  packaging and fails at import resolution. Bazel-built upstream never sees it.
- Builds green on darwin/arm64, linux/arm64, linux/amd64, `CGO_ENABLED=0`, including
  `link/fdbased`, `link/channel`, `link/sniffer`, `adapters/gonet`, ipv4/ipv6/tcp/udp/icmp.
- **No Go version bump needed** — the pin declares `go 1.25.5`; head would have forced
  `go >= 1.26.3`.
- **The `FaultEndpoint` decorator shape is validated, not assumed** — a `stack.LinkEndpoint`
  decorator over `link/channel` was accepted by `stack.CreateNIC`, NIC up at MTU 1500.
- Cost: **+6.5 MB (~+13%)** against the 47.4 MB baseline. `nogvisor` build tag withdrawn.

**Carried into M1:** a CI check asserting the pinned version still builds on all three
targets, so an attempted dependency bump fails loudly rather than silently breaking.

### 0.2 Insertion spike — ✅ DONE (2026-07-28)

Full result in
[RFC-054 § Decision record M0.2](../rfcs/0054-gvisor-packet-and-file-mediation.md#decision-record-m02--insertion-mechanism).
Both candidates were prototyped in the Lima VM against real containers.

- **Candidate A (TUN + routed subnet) is the fault gateway.** Full TCP lifecycle observed at
  the `FaultEndpoint` with `flags`/`seq`/`window`/`len` — every field the matcher needs.
- **A container reached netstack with no iptables changes**, contradicting this plan's
  prediction that Docker's `FORWARD policy DROP` would block it.
- **Candidate B cannot drop.** `AF_PACKET`/`ETH_P_ALL` copies frames the kernel already
  delivered — it is a tap, not a gateway. It is retained as a **future detection mode**,
  since it sees all container traffic with true source IPs and zero setup.
- **Source attribution is a non-issue**: the gateway assigns one netstack address per
  `(consumer, target-interface)` pair, so no NAT exemption or firewall rules are needed.

### 0.3 runsc + seccheck spike — ✅ DONE (2026-07-28)

Full result in
[RFC-054 § Decision record M0.3](../rfcs/0054-gvisor-packet-and-file-mediation.md#decision-record-m03--runsc--seccheck).

- **Postgres and Redis both work under runsc.** The RFC-046 compatibility worry did not
  materialize. Install is non-invasive — the default runtime stays `runc`.
- **The sink works end-to-end**: handshake completed, 1054 points streamed over
  `SOCK_SEQPACKET`.
- **Real byte offsets confirmed** — 263 of 268 writes were `pwrite64` carrying
  `offset`/`count`/`result`, plus 57 failed opens with true errno.
- **Fixtures decode on macOS with no runsc**, proving the M5 host-test strategy.
- ⚠️ **No `fsync` trace point exists.** Scenario 10 is withdrawn; `watch(ops=["fsync"])`
  will be rejected at spec load rather than silently emitting nothing.
- ⚠️ **`openat` reports a raw, often relative `pathname`.** Matching keys on `fd_path` from
  read/write/close; `openat` resolution needs dirfd + pathname + `cwd`.

### 0.4 Baseline capture — ✅ DONE (2026-07-28)

Committed as [`v0.14.0-baseline.txt`](v0.14.0-baseline.txt). Build, vet, and the full
`-race` suite: **0 failures**. Cross-compile green for both binaries. `bin/faultbox` =
47.4 MB.

## Milestone 1 — Netstack foundation (`internal/netfault`)

**Goal:** a fully tested packet fault engine with **no** dependency on how packets arrive.
Everything here runs over `link/channel`, so it is testable on macOS.

### 1.1 Package skeleton

```
internal/netfault/
  endpoint.go        FaultEndpoint — stack.LinkEndpoint decorator
  endpoint_test.go
  packetview.go      PacketView — parsed header projection, zero-copy where possible
  packetview_test.go
  rule.go            Rule, Action, compiled matcher predicate
  rule_test.go
  match.go           declarative matcher evaluation
  match_test.go
  defer.go           deferQueue — single-goroutine timer wheel
  defer_test.go
  stack.go           Stack construction, NIC setup, address assignment
  stack_test.go
```

### 1.2 `FaultEndpoint`

Decorator over `stack.LinkEndpoint`, modeled on `pkg/tcpip/link/sniffer`. Intercepts
`WritePackets` (egress) and `DeliverNetworkPacket` (ingress). Rules held in an
`atomic.Pointer[ruleSet]` so installation is lock-free on the datapath.

### 1.3 Actions

`drop`, `delay`, `reorder`, `duplicate`, `corrupt`, `reset`, `window`, `pass`.

`reset` synthesizes a TCP RST with correct sequence numbers and drops the original.
`corrupt` mutates payload bytes at an offset with `checksum="fix"|"break"`. `window`
rewrites the advertised receive window in the TCP header and recomputes the checksum.

### 1.4 `deferQueue`

Single goroutine, monotonic-tick timer wheel. Equal deadlines release in insertion order.
**Not** one goroutine per delayed packet — that would make reordering nondeterministic and
reintroduce the exact ambiguity L1 already refuses to promise away.

### 1.5 Occurrence counters

`nth` / `after` / `every` and `probability` / `max_fires` / `mode`. The probability path
**reuses `engine.FaultRule`'s existing decider semantics verbatim** rather than
reimplementing them — RFC-042 §8.9 exhaustive fan-out must behave identically for packet
faults and syscall faults, and two implementations would drift.

### Tests

| Test | Asserts |
|---|---|
| `TestFaultEndpointPassthrough` | Zero rules ⇒ byte-identical delivery, both directions |
| `TestDropMatchingSegments` | `drop` removes only matching packets; others delivered |
| `TestDropIsSilent` | Dropped packet produces **no** RST — the half-open case from RFC-054 scenario 1 |
| `TestDelayPreservesOrder` | Equal-deadline packets release in insertion order |
| `TestDelayReleasesAfterDuration` | Fake clock: released at d, not before |
| `TestReorderByN` | Packet N delivered after N+k |
| `TestDuplicateDeliversTwice` | Exactly two deliveries, both well-formed |
| `TestCorruptFixChecksum` | `checksum="fix"` ⇒ receiver accepts; `"break"` ⇒ receiver drops |
| `TestResetSynthesizesRST` | RST has correct seq/ack; original never delivered |

## Milestone 2 — Packet DSL (`internal/star`)

**Goal:** spec authors can write packet faults. Wired to the M1 engine; not yet to real
traffic.

### 2.1 Builtins

`packet_drop`, `packet_delay`, `packet_reorder`, `packet_duplicate`, `packet_corrupt`,
`packet_reset`, `packet_window`.

`bandwidth()` and `mtu()` are **deferred to v0.14.1** — they are link-scoped shapers
needing a token bucket and real fragmentation handling, not per-packet rules.

Each returns a `PacketFaultDef`, accepted positionally by `fault(iface_ref, ...)` alongside
the existing `ProxyFaultDef` values.

**One shared kwarg parser**, following the precedent set by the v0.13.2 fix
(`df781ca fix(spec): proxy fault builtins reject unknown kwargs via one shared matcher parser`).
Unknown kwargs are rejected at spec load with a migration hint. This is not optional — the
project has already paid for the alternative once.

### 2.2 `Packet` Starlark type

Read-only `starlark.Value` with the fields from RFC-054. `payload` capped at 4 KiB
(configurable). Immutable, no methods with side effects.

### 2.3 Matcher compiler

Declarative kwargs compile to a closed-form Go predicate — no Starlark, no allocation on
the datapath. `where=` is evaluated **only** for packets that already passed the
declarative predicate, and only under a per-test evaluation counter that warns past a
threshold.

### 2.4 Event family

`packet` events: `action`, `direction`, `proto`, `src`, `dst`, `len`, `flags`, `flow`,
`rule_label`. Follows the existing `proxy` event conventions, including the `action` and
`protocol` fields added in v0.13.3 (`e93bbc6`).

### 2.5 Runtime gating

`determinism(runtime="gvisor")` becomes an accepted value (it errored as reserved syntax
before). A `packet_*` fault under `runtime="default"` **fails loudly** naming the fix, not a
silent no-op — consistent with the v0.13.x direction.

### Tests

| Test | Asserts |
|---|---|
| `TestPacketBuiltinsParse` | Every builtin, every kwarg, correct `PacketFaultDef` |
| `TestPacketBuiltinsRejectUnknownKwargs` | Each builtin, with hint text |
| `TestPacketFaultRequiresGvisorRuntime` | Clear error under `runtime="default"` |
| `TestRuntimeGVisorAccepted` | No longer reserved syntax |
| `TestRuntimeGVisorNetNoLongerExists` | Only two runtimes exist |
| `TestDeterminismL2StillErrors` | **Ceiling unchanged** — the anti-overclaim guard |
| `TestPacketTypeFields` | Every field readable; `payload` capped; immutable |
| `TestWhereLambdaEvaluated` | Lambda receives a correct `Packet` |
| `TestWhereLambdaOnlyAfterDeclarative` | Lambda not called for declaratively-excluded packets |
| `TestMatcherCompilerEquivalence` | Compiled predicate ≡ naive reference over a generated corpus |
| `TestPacketEventSchema` | Stable fields present |
| `TestDelayOverloadUnaffected` | `delay("500ms")` and `delay(path=...)` behave **exactly** as before |

### Exit criteria

- [ ] Regression gate green, diffed against baseline
- [ ] testops corpus gate green — no shipped `.star` changes behavior
- [ ] `TestDelayOverloadUnaffected` green (the highest-risk regression in the release)

## Milestone 3 — Path matcher retrofit (independent user-visible fix)

**Goal:** ship the doublestar path matcher and fix a bug users hit today. **Zero gVisor
dependency.** Placed here deliberately: if Milestones 4–5 slip, v0.14.0 still delivers
this.

### 3.1 `internal/pathmatch`

`**`-capable glob shared by `engine.FaultRule.MatchPath`, the M5 `watch()` matcher, and the
existing `op(path=)` plumbing. Replaces `filepath.Match` at
[`fault.go:18-29`](../../internal/engine/fault.go) and removes the *"For the PoC this is
fine"* comment.

### 3.2 Backward compatibility

Every pattern that matches today must still match. The retrofit is a **widening**:
`/data/*` keeps matching `/data/foo`, and additionally `/data/**` now matches
`/data/a/b/c`, which previously silently matched nothing.

### 3.3 Diagnose silent no-match

When a path-globbed rule ends a fault window with `MatchCount() == 0`, the existing
"no injections fired" reporting (v0.9.4) gains a note distinguishing *no syscalls occurred*
from *path resolution failed* (empty path from `/proc`) — the current failure mode is
indistinguishable from the rule simply not firing, which is the root of the footgun.

### Tests

| Test | Asserts |
|---|---|
| `TestPathMatchBackCompat` | Table of every pattern in the shipped corpus, before ≡ after |
| `TestDoubleStarCrossesSegments` | `/data/**/*.wal` matches `/data/a/b/x.wal` |
| `TestSingleStarDoesNotCrossSegments` | `/data/*` does **not** match `/data/a/b` |
| `TestPathTruncationDiagnosed` | Path > 256 bytes ⇒ diagnostic, not silence |
| `TestNoMatchReportsResolutionFailure` | Distinguishes the two zero-match causes |

### Exit criteria

- [ ] Regression gate green, diffed against baseline

## Milestone 4 — Gateway insertion (Linux)

**Goal:** packet faults act on real SUT traffic. Implements the mechanism chosen in M0.2.

### 4.1 Insertion — candidate A (TUN + routed subnet)

Faultbox creates the TUN, assigns `10.99.0.0/16`, and allocates **one netstack address per
`(consumer, target-interface)` pair** so the destination alone identifies both ends — this
is what makes `source=` targeting work without any NAT or firewall mutation. RFC-024's
env-rewrite insertion contract is reused unchanged.

Lifecycle owned by `internal/container` alongside the existing network setup, torn down with
the session — with an explicit test for teardown, given the proxy-lifecycle findings in
[`docs/design/2026-04-27-proxy-lifecycle-findings.md`](../design/2026-04-27-proxy-lifecycle-findings.md).

### 4.2 Wiring

Interface refs resolve to a gateway link; `fault(db.main, packet_drop(...))` installs rules
on that link's `FaultEndpoint`; `fault_stop` removes them.

### 4.3 Preflight

Missing `CAP_NET_ADMIN`, missing `ip_forward`, unsupported kernel ⇒ actionable error at
service start naming the exact remediation. Not a stack trace, not a silent degrade.

### 4.4 Scenario corpus

The **eleven** surviving RFC-054 scenarios as executable specs under `poc/gvisor-rfc054/`,
following the `poc/kafka-rfc014/` precedent. (Scenario 10 was withdrawn in M0.3 — no
`fsync` trace point.)

### Tests

| Test | Asserts |
|---|---|

| `TestGatewayPassthroughUnchanged` | No rules ⇒ SUT behavior identical to no gateway |
| `TestGatewayTeardown` | No leaked TUN/veth/netns/goroutines after the session |
| `TestGatewaySurvivesContainerRestart` | Works with `reuse=True` |

## Milestone 5 — File I/O observation (`internal/gvisor/seccheck`)

**Goal:** `watch()` emits `file_io` events with resolved paths, offsets, and counts.

### 5.1 Sink

`SOCK_SEQPACKET` UDS server, mode `0600` in the session directory. Handshake, wire header
decode, protobuf payload decode.

**Security requirement, not a nicety:** gVisor's threat model treats the Sentry as
untrusted and its README mandates hard size limits on every field. The decoder enforces
them, and there is a fuzz test that says so.

### 5.2 runsc integration

Container launch with `Runtime: "runsc"` + trace session config. Availability detection
with an actionable spec-load error.

### 5.3 `watch()` / `watch_start()` / `watch_stop()`

Scoped like `fault()`. Path filtering via the M3 matcher. Emits `file_io` events.

### 5.4 `file_io()` query helper

`bytes_written`, `bytes_read`, `count(op=)`, `paths()`.

### 5.5 `fs-unmediated` detection

The reserved category from [`determinism.go:44-46`](../../internal/star/determinism.go)
finally emits events, closing RFC-040's outstanding commitment.

### Tests

Fixture-driven from the M0.3 `tracereplay` captures, so **the decoder is fully tested on
macOS without runsc**:

| `TestSeccheckFuzzDecoder` | `go test -fuzz`, no panic on arbitrary input |
